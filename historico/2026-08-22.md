## 📝 Decisões técnicas importantes
- Prisma: instalou v7 por padrão (breaking changes recentes) → fixado em v6, mais compatível com `@auth/prisma-adapter`
- Auth do painel interno: cookie HMAC-SHA256 via Web Crypto (não Node `crypto`) pra funcionar tanto no middleware Edge quanto em server actions
- "Resultado em pontos" é o movimento de preço (independe de contratos); "resultado em $" multiplica por `valorPorPonto * contratos`
- Cálculo do trade é sempre recalculado no servidor (nunca confia no valor mostrado no formulário do cliente)
- Print do trade salva em `public/uploads` por enquanto (não funciona no Vercel — trocar por Vercel Blob antes do deploy)

## ⚠️ Problemas encontrados e soluções
- Problema: npm cache com arquivos root-owned, `npm install` falhando
  - Solução: cache alternativo no scratchpad (`npm_config_cache=...`), sem precisar de `sudo chown`
- Problema: `npx prisma dev` (Postgres local) não funciona sem Docker rodando
  - Solução: usamos direto o Neon real do Marcelo (connection string do projeto `neondb`)
- Problema: badge de Compra/Venda usava verde/vermelho e confundia com resultado do trade
  - Solução: badge de lado ficou neutro; cor de resultado só aparece no %/pontos
